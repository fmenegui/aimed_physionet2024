# Licensing status and third-party notices

The inspected `cinc_of5` snapshot contains no root license file. Its historical
`media/setup.py` has an MIT classifier, but the corresponding MIT license text
and copyright grant are absent from that snapshot. This release does not infer
a repository-wide license from that metadata.

The two pinned Hugging Face repositories have no declared license in the model
card metadata returned by the Hub at inspection time. Public downloadability
alone does not specify the terms for using or redistributing model weights.

The maintainers still need to specify explicit terms for AIMED-authored code
and for the trained weights. Contact the authors before relying on a particular
permission for these materials. No new use restriction or license grant is
introduced by this notice.

The Challenge scaffold has a separate BSD-2-Clause notice, retained in
[`LICENSES/PhysioNet-BSD-2-Clause.txt`](LICENSES/PhysioNet-BSD-2-Clause.txt).
The source includes its `helper_code.py`, `train_model.py`, `run_model.py`,
`evaluate_model.py`, preparation scripts and template-derived entry points.
That notice must be retained for the corresponding material.

Third-party libraries and datasets have their own terms. No private InCor data
are distributed by this repository.
